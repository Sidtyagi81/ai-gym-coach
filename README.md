# AI Gym Coach

AI-powered fitness coach that uses real-time pose detection to help users track their exercise form and repetitions.

## Features

- Real-time exercise tracking
- Pose detection using MediaPipe
- Exercise repetition counting
- AI-powered workout assistance
- Interactive web interface

## Project Structure

- `LandingPage/` — Project landing page
- `MainApp/` — Main AI Gym Coach application
- `ml_models/` — Machine learning models

## Technologies

- Python
- Streamlit
- MediaPipe
- OpenCV
- Machine Learning
